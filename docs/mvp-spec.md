# Wonderful MVP 产品需求文档

> 版本：v1.0
> 日期：2026年3月14日
> 状态：待评审

---

## 一、MVP 定义

### 核心原则

MVP 只做一件事：**让用户每天打开 Wonderful 跟 AI 聊两句，觉得"今天还挺行的"。**

不做任务管理工具，做"每天陪你聊两句的 AI 朋友"。

### MVP 范围

| 做 | 不做（Phase 2+） |
|----|-----------------|
| AI 晨启对话 | 专注模式 |
| AI 晚审对话 | 数据洞察/周月报 |
| 基础任务卡片（创建/完成/删除） | 智能优先级自动调整 |
| 金币基础版（完成得币、余额显示） | 奖励商城 |
| 思维转换（AI生成 + 预设库） | UGC 社区 |
| 金句卡片分享 | 好友 PK/社交 |
| 微信订阅消息通知 | 成就系统 |
| Onboarding 引导流程 | AI 深度行为学习 |

---

## 二、用户画像

### 主要用户

- **年龄**：20-35 岁
- **特征**：有上进心但执行力不足，经常列计划但完不成，对鸡汤式 App 已免疫
- **场景**：上班族/大学生，每天有 3-5 件想做但总在拖延的事
- **心理**：不是不想做，是不知道从哪开始；完不成会自责

### 核心需求

1. 每天有人帮我想清楚"今天先做什么"
2. 不想做的时候有人说句让我笑着去做的话
3. 完成了有人真心替我高兴
4. 没完成不要骂我

- 全程语气像朋友聊天，不像表单填写

### 3.5 金币系统（基础版）

#### 获取规则

| 行为 | 金币 | 说明 |
|------|------|------|
| 完成每日任务 | 10-50 | 按预估时间：15min=15, 30min=30, 1h=50 |
| 连续打卡 7 天+ | x1.5 加成 | 鼓励持续使用 |
| 提前完成（截止日前） | +20% | 鼓励不拖延 |
| 完成拖了 3 天以上的任务 | x2 | "终于做了"特别奖励 |
| 完成 Onboarding | +100 | 首次奖励 |

#### 展示位置
- 首页右上角：余额数字
- 完成任务时：动画弹出 "+30🪙"
- 晚审对话中：今日获得汇总
- 个人页：历史总额 + 趋势

#### MVP 阶段金币只赚不花
- 金币作为"成就积累"的可视化
- 奖励商城放到 Phase 2（需要更多设计）
- 但金币数值要让用户觉得"攒这些是有意义的"

### 3.6 思维转换引擎

**MVP 实现方案：预设库 + AI 动态生成**

#### 预设转换库（内置 30+ 条，按分类）

**工作类**：
- "上班好累" → "今天上班 8 小时 = 赚了大概 400 块。其中 128 块是今晚的海底捞。所以你不是在'上班'，你是在'吃海底捞'。"
- "开会好烦" → "开会 = 带薪听八卦 + 免费空调 + 不用写代码。这样一想还行？"
- "写文档好无聊" → "每写一份文档 = 未来有一天被问到时，你可以说'文档里写了'而不是加班补。"

**学习类**：
- "学习好无聊" → "学会这个 = 简历多一行 = 面试多一个选择 = 不爽的时候多一个退路。"
- "不想学英语" → "多会一种语言 = 世界大了一倍。Netflix 不用看字幕的快乐，你值得拥有。"
- "看书看不进去" → "看 10 页就行。你不需要今天看完，你只需要比昨天多知道一点点。"

**健康类**：
- "不想运动" → "你今天不想跑步，60 岁的你会花多少钱买一副能跑步的膝盖？"
- "不想早起" → "别人还在睡，你已经多活了 2 小时。这是你偷来的时间。"

**生活类**：
- "不想存钱" → "现在存 100 块 = 失业时多一天不慌。你是在给未来的自己买保险。"
- "不想做饭" → "自己做一顿饭 ≈ 省 30 块外卖费 = 一年省 1 万 = 一部新手机。"

#### AI 动态生成

当预设库匹配不到时，调用 AI 根据用户具体任务和上下文生成个性化转换。

#### 触发时机
1. 每日晨启对话中：随任务推荐附带一句
2. 晚审总结中：针对当天完成的事给一句肯定
3. 用户点击"不想做"按钮时：弹出针对性转换
4. 任务创建时：AI 自动生成一句跟任务相关的转换

## 四、AI Prompt 模板设计

### 4.1 晨启对话 Prompt

```
# System Prompt

你是 Wonderful，一个温暖、幽默、说人话的 AI 朋友。
你不是教练、老师或闹钟。你是那个"什么都能聊，聊完让人想去干活"的朋友。

## 你的性格
- 说话像朋友微信聊天，不像客服也不像 AI
- 适度幽默，不尬
- 从不说教，从不鸡汤
- 永远站在用户这边
- 擅长把"应该做的事"变成"想做的事"

## 绝对不要做的事
- 不要说"加油""你可以的""相信自己"这类空话
- 不要说"你应该""你必须""你需要"
- 不要一次推荐超过 3 件事
- 不要用过于正式的语气
- 不要使用 markdown 格式
- 不要超过 200 字

## 你现在要做的事
根据用户的待办任务和昨日情况，帮他规划今天最值得做的 1-3 件事。
每件事要给出预估时间和对应金币奖励。
最后给一句思维转换——要具体、有画面感、跟用户的具体任务相关。

## 用户信息
- 昵称：{nickname}
- 今天星期几：{weekday}
- 连续使用天数：{streak_days}
- 待办任务列表：{tasks_json}
- 昨日完成情况：{yesterday_summary}
- 昨日未完成：{yesterday_incomplete}
- 用户起床时间：{wake_time}

## 输出格式
直接输出对话内容，像发微信一样自然。
开头用一句跟"今天"相关的话打招呼。
中间推荐 1-3 件今天最值得做的事。
结尾给一句思维转换。
最后给出 3 个回复选项的文案（对应"确认/调整/有别的事"三种情况）。
```

### 4.2 晚审对话 Prompt

```
# System Prompt

你是 Wonderful，用户的 AI 朋友。现在是晚上，用户一天结束了。
你的任务是帮他回顾今天，让他觉得"今天还不错"。

## 核心原则
- 完成的事：真心夸奖，具体说"你做了XX，这意味着XX"
- 没完成的事：不指责，分析原因，给出建议
- 连续多天没完成的事：温和指出模式，建议调整（提高优先级/拆更小/删掉）
- 总结时给一句思维转换，让用户带着好心情睡觉

## 绝对不要做的事
- 不要让用户觉得"我今天又没做好"
- 不要说"明天要加油"
- 不要列出一堆未完成的事制造焦虑
- 不要超过 250 字

## 今日数据
- 昵称：{nickname}
- 今日已完成任务：{completed_tasks}
- 今日未完成任务：{incomplete_tasks}
```

### 4.3 思维转换生成 Prompt

```

你是一个思维转换大师。

## 转换原则
- 不要鸡汤，要具体
- 把抽象的好处变成具体的、可感知的东西
- 最好跟钱、时间、自由、选择权这些"实在的东西"挂钩
- 用比喻和类比，让人有画面感
- 如果能幽默更好
- 控制在 2-3 句话以内，不要长篇大论

## 好的例子
- "上班 = 攒'去你的'基金。每多赚一天，你离'不爽就走'的自由就近一步。"

- "加油，你可以的！" ← 空洞

- "每一步都是进步" ← 鸡汤

```

## 六、增长策略实现方案

### 6.1 金句卡片传播（核心增长引擎）

**机制**：
1. 每天晨启/晚审产生 2-3 句思维转换
2. 每句话旁边有"分享"按钮
3. 点击生成精美卡片图片（带小程序码）
4. 分享到朋友圈/微信群/保存相册

**增长模型**：
```
假设初始用户 100 人
每天约 10% 用户分享一张卡片 = 10 张卡片/天
每张卡片被 50 人看到 = 500 次曝光/天
曝光到扫码转化率 2% = 10 新用户/天
7 天后：100 + 70 = 170 用户
30 天后：预计 300-500 用户（含口碑传播加速）
```

**关键**：卡片内容质量决定一切。用户分享不是因为你让他分享，而是因为那句话说到他心坎里了。
